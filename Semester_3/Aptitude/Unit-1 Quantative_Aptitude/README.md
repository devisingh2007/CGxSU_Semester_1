# 1. Average

### 1.1. What is an Average

Average means finding one single value that represents a group of numbers.

### 1.2. Basic Formula

```
Average = Sum of all values / Number of values
```

### 1.3. Finding the Total from the Average

If we already know the average, we can find the total by flipping the formula.

```
Total = Average × Number of values
```

### 1.4. Finding a Missing Value

If we know the average of a group and all values except one, we can find the missing value.

Example: Average of 5 numbers is 24. Four numbers are 20, 22, 25, 28. Find the fifth.

```
Total = 24 × 5 = 120
Sum of known 4 numbers = 20+22+25+28 = 95
Missing number = 120 − 95 = 25
```

### 1.5. Adding a New Value

When a new value joins the group, both the total and the number of values increase.

Example: Average of 10 students is 60. A new student scores 80. Find the new average.

```
Old total = 10 × 60 = 600
New total = 600 + 80 = 680
New average = 680/11 = 61.8 (approx)
```

### 1.6. Removing a Value

When a value is removed, both the total and the number of values decrease.

Example: Average of 8 numbers is 25. One number, 32, is removed. Find the new average.

```
Old total = 25 × 8 = 200
New total = 200 − 32 = 168
New average = 168/7 = 24
```

### 1.7. Replacing a Value

When one value is replaced by another, the number of values stays the same, only the total changes.

```
New Total = Old Total − Old Value + New Value
```

### 1.8. When Every Value Changes by the Same Amount

If every single value in a group goes up or down by the same amount, the average also changes by that same amount.

Example: Average marks of a class is 65. Every student gets 5 extra marks.

```
New average = 65 + 5 = 70
```

### 1.9. Combining Two Groups (Combined Average)

When two groups are joined together, we cannot simply average their two averages — we must use the actual totals.

```
Combined Average = (n1×Average1 + n2×Average2) / (n1 + n2)
```

### 1.10. Weighted Average

Used when different values carry different importance (called "weight").

```
Weighted Average = (x1×w1 + x2×w2 + ...) / (w1 + w2 + ...)
```

### 1.11. Average Speed

```
Average Speed = Total Distance / Total Time
```

### 1.12. Average of Equally Spaced (Consecutive) Numbers

If numbers increase by the same gap each time (like 11,12,13,14,15), you don't need to add everything — just use:

```
Average = (First number + Last number) / 2
```

# 2. Percentage

### 2.1. What is a Percentage

"Percent" means "out of 100." When we say 20%, we mean 20 out of every 100.

So, x% simply means the fraction x/100.

### 2.2. Converting Between Fractions, Decimals and Percentages

**Fraction to Percentage:** Multiply the fraction by 100  
``` (3/4 × 100 = 75%) ```

**Percentage to Fraction:** Divide the percentage by 100 and simplify  
``` (40% = 40/100 = 2/5) ```

**Decimal to Percentage:** Multiply the decimal by 100  
``` (0.65 × 100 = 65%) ```

**Percentage to Decimal:** Divide the percentage by 100  
``` (12% = 12/100 = 0.12) ```

### 2.3. Useful Fraction–Percentage Values

It helps to know some common fractions and their percentage values, since they appear again and again in problems.

| Fraction | Percentage |
|----------|-----------|
| 1/2 | 50% |
| 1/3 | 33.33% |
| 1/4 | 25% |
| 1/5 | 20% |
| 1/6 | 16.67% |
| 1/8 | 12.5% |
| 1/10 | 10% |

### 2.4. How to Find a Percentage of a Number

To find x% of a number N, use this formula:  
``` x% of N = (x / 100) × N ```

### 2.5. Percentage Increase and Percentage Decrease

**When a value increases by x%:**

New value = Original value + x% of Original value :
``` New value = Original value × (1 + x/100) ```

**When a value decreases by x%:**

New value = Original value − x% of Original value :
``` New value = Original value × (1 − x/100) ```

**General Formula for Percentage Change**

``` Percentage change = [(New value − Original value) / Original value] × 100 ```

If the answer is positive, it is a percentage increase.  
If the answer is negative, it is a percentage decrease.

### 2.6. When a Value Changes Twice (Successive Percentage Change)

Sometimes a quantity changes two times in a row. For example, a price is increased by 10%, and then decreased by 10%. Many students assume the two changes cancel out and the final answer is 0%. This is not correct, and it is important to understand why.

**Why simple addition does not work**

When you increase a number by 10%, the number becomes bigger.  
When you then decrease this new (bigger) number by 10%, you are taking 10% of a bigger number, so the decrease is a bigger amount than the original increase.

This is why the two changes do not cancel out.

**Formula for combining two successive percentage changes**

If a quantity changes by a% and then by b% (one after the other), the total (net) percentage change is:

``` Net % change = a + b + (a × b)/100 ```

### 2.7. Price and Consumption Problems

This is a common type of problem: if the price of something increases, by how much should you reduce how much you buy, so that your total spending stays the same?

**If price increases by x%, the reduction needed in consumption is:**

Required % decrease in consumption : ``` [x / (100 + x)] × 100 ```

**If price decreases by x%, the increase allowed in consumption is:**

Required % increase in consumption : ``` [x / (100 − x)] × 100 ```

### 2.8. Simple Word Problems Based on Percentage

**Population Growth**

If a population P grows at r% every year, then after n years, the new population is:

New population : ``` P × (1 + r/100)^n ```

# 3. Probability

### 3.1. Basic Formula

```
Probability of an event = Number of favourable outcomes / Total number of possible outcomes
```

Probability always lies between 0 and 1.

```
0 ≤ P(event) ≤ 1
```

### 3.2. Sample Space

The sample space is the set of all possible outcomes of an experiment.

```
Example setup: Tossing a coin → Sample space = {Head, Tail}
Rolling a die → Sample space = {1, 2, 3, 4, 5, 6}
```

### 3.3. Complementary Event

The probability that an event does NOT happen is 1 minus the probability that it does happen.

```
P(not A) = 1 − P(A)
```

### 3.4. Addition Rule (Either Event Happens)

**For mutually exclusive events (cannot happen at the same time):**

```
P(A or B) = P(A) + P(B)
```

**For events that can happen together:**

```
P(A or B) = P(A) + P(B) − P(A and B)
```

### 3.5. Multiplication Rule (Both Events Happen)

**For independent events (one does not affect the other):**

```
P(A and B) = P(A) × P(B)
```

### 3.6. Cards (Standard Deck)

```
Total cards = 52
Red cards = 26, Black cards = 26
4 suits: Spades, Hearts, Diamonds, Clubs (13 cards each)
Face cards = 12 (Jack, Queen, King of each suit)
```

### 3.7. Dice

```
A single die has 6 faces: 1, 2, 3, 4, 5, 6
Two dice thrown together give 36 total outcomes (6 × 6)
```

### 3.8. Coins

```
One coin tossed → 2 outcomes
Two coins tossed together → 4 outcomes
n coins tossed together → 2ⁿ outcomes
```

### 3.9. Combinations in Probability (Choosing Items)

When probability involves choosing a group of items (like balls from a bag), the number of ways to choose is found using combinations.

```
Number of ways to choose r items from n items = n! / (r! × (n−r)!)

Probability = (Favourable combinations) / (Total combinations)
```

### 3.10. Conditional Probability

The probability of an event happening, given that another event has already happened.

```
P(A given B) = P(A and B) / P(B)
```

# 4. Profit and Loss

### 4.1. Basic Terms

CP (Cost Price) is the price at which an item is bought. SP (Selling Price) is the price at which it is sold.

```
Profit = SP − CP
Loss = CP − SP
```

### 4.2. Profit % and Loss %

Always calculated on the cost price, never on the selling price.

```
Profit % = (Profit / CP) × 100
Loss % = (Loss / CP) × 100
```

### 4.3. Finding SP from CP

```
SP = CP × (100 + Profit%) / 100
SP = CP × (100 − Loss%) / 100
```

### 4.4. Finding CP from SP

```
CP = SP × 100 / (100 + Profit%)
CP = SP × 100 / (100 − Loss%)
```

### 4.5. Marked Price and Discount

Discount is always calculated on the marked price (MP), not on the cost price.

```
Discount = MP − SP
Discount % = (Discount / MP) × 100
SP = MP × (100 − Discount%) / 100
```

### 4.6. Successive Discounts

Two discounts do not simply add up, since the second is applied on the already reduced price.

```
Equivalent single discount = a + b − (ab/100)
```

### 4.7. Connecting MP, CP and SP

```
MP → apply discount → SP → compare with CP → profit or loss
```

### 4.8. Selling Two Items at the Same Price

If two items are sold at the same price, one at x% profit and the other at x% loss, the result is always a loss.

```
Loss % = (x × x) / 100
```

### 4.9. Dishonest Shopkeeper (False Weight)

```
Gain % = [Error / (True Value − Error)] × 100
```

### 4.10. Profit Based on Number of Articles

```
If CP of x articles = SP of y articles
Profit % = [(x − y) / y] × 100
```

### 4.11. Marking Above Cost Price and Then Giving a Discount

```
MP = CP × (100 + Markup%) / 100
SP = MP × (100 − Discount%) / 100
```

# 5. Ratio & Proportion

### 5.1. What is a Ratio

A ratio compares two quantities of the same kind by division. The ratio of a to b is written as a : b, meaning a/b.

Both quantities must be in the same unit, and the order matters — a:b is not the same as b:a.

### 5.2. Simplifying a Ratio

Divide both terms by their HCF, just like simplifying a fraction.

```
20 : 15 → HCF = 5 → 4 : 3
```

For ratios with fractions, take the LCM of the denominators and multiply through.

```
2/3 : 3/4 → LCM = 12 → 8 : 9
```

### 5.3. Dividing a Quantity in a Given Ratio

If N is divided in the ratio a : b:

```
First part = N × a/(a+b)
Second part = N × b/(a+b)
```

### 5.4. Comparing Ratios

Convert each ratio to a decimal and compare.

```
3:4 = 0.75
5:7 = 0.714
```

Since 0.75 > 0.714, 3:4 is greater.

### 5.5. Combining Two Ratios

To combine A:B and B:C into A:B:C, make the value of B equal in both ratios first (using their LCM), then combine.

```
A:B = 2:3 and B:C = 4:5
LCM of 3, 4 = 12
A:B = 8:12, B:C = 12:15
A:B:C = 8:12:15
```

### 5.6. Proportion

Two ratios that are equal form a proportion: a : b :: c : d, meaning a/b = c/d.

**Cross multiplication rule**

```
a : b = c : d  →  a × d = b × c
```

### 5.7. Continued Proportion

a, b, c are in continued proportion if a : b = b : c, which means:

```
b² = a × c
```

Here b is the mean proportional between a and c.

**Third proportional:** if a, b are given, find c using the same formula b² = a × c.

### 5.8. Direct Proportion

Two quantities increase or decrease together, keeping their ratio constant.

```
x1/y1 = x2/y2
```

### 5.9. Inverse Proportion

One quantity increases while the other decreases, keeping their product constant.

```
x1 × y1 = x2 × y2
```

**How to tell direct from inverse:** ask whether increasing one quantity increases or decreases the other. Both increase/decrease together → direct. One up, other down → inverse.

### 5.10. Ratio and Percentage Together

If two quantities are in ratio a:b:

```
First quantity % of total = [a/(a+b)] × 100
Second quantity % of total = [b/(a+b)] × 100
```

# 6. Time and Work

### 6.1. One Day's Work

If a person finishes a work in n days, their 1 day's work is:

```
1 day's work = 1 / n
Days needed to finish work = 1 / (1 day's work)
```

### 6.2. Work Done in Several Days

```
Work done in x days = x × (1 day's work)
```

### 6.3. Two or More People Working Together

```
Combined 1 day's work = 1/A + 1/B + ...
Days to finish work together = 1 / (Combined 1 day's work)
```

### 6.4. Shortcut for Two People Working Together

If A alone takes 'a' days and B alone takes 'b' days:

```
Days together = (a × b) / (a + b)
```

### 6.5. Efficiency and Time

A faster (more efficient) person takes fewer days. Efficiency and time are inversely related.

```
Efficiency ∝ 1 / Time taken
If Efficiency A : Efficiency B = m : n, then Time A : Time B = n : m
```

### 6.6. Work and Wages

Payment is split in the same ratio as the work each person did (their efficiency).

```
Wage ratio = Efficiency ratio = 1/(Days taken by each person)
```

### 6.7. Men, Days and Work (Group Comparison)

```
M1 × D1 / W1 = M2 × D2 / W2
M1 × D1 × H1 / W1 = M2 × D2 × H2 / W2  (if hours per day are given)
```

### 6.8. People Joining or Leaving Midway

Split the work into stages and add up the work done in each stage.

```
Work done in a stage = (Workers × Days worked) / (Days needed by 1 worker alone)
```

### 6.9. Pipes and Cisterns

Filling is positive work, draining is negative work.

```
Inlet pipe's 1 hour work = + 1/n
Outlet pipe's 1 hour work = − 1/n
```

### 6.10. Filling and Draining Together

```
Net 1 hour work = (Total filling work) − (Total draining work)
Time to fill/empty = 1 / (Net 1 hour work)
```

### 6.11. Alternating Work Pattern

```
Work done in one round = Sum of work by each person/pipe in their turn
Number of rounds needed = Total work / Work done per round
```

# 7. Time, Speed and Distance

### 7.1. Basic Formula

```
Speed = Distance / Time
Distance = Speed × Time
Time = Distance / Speed
```

### 7.2. Unit Conversion

```
To convert km/hr to m/s, multiply by 5/18
To convert m/s to km/hr, multiply by 18/5
```

### 7.3. Average Speed

Average speed depends on total distance and total time, not the simple average of speeds.

```
Average Speed = Total Distance / Total Time
```

**Equal distance covered at two speeds a and b:**

```
Average speed = 2ab / (a + b)
```

**Equal time intervals at two speeds a and b:**

```
Average speed = (a + b) / 2
```

### 7.4. Relative Speed

Used when two objects move and we need their speed with respect to each other.

```
Same direction: Relative speed = Difference of speeds
Opposite direction: Relative speed = Sum of speeds
```

### 7.5. Time Taken to Meet or Cross Each Other

```
Time = Distance between them / Relative speed
```

### 7.6. Trains Crossing Objects

**Crossing a stationary point or pole (train's own length only):**

```
Time = Length of train / Speed of train
```

**Crossing a platform or bridge (train's length + platform length):**

```
Time = (Length of train + Length of platform) / Speed of train
```

### 7.7. Two Trains Crossing Each Other

```
Time = (Sum of lengths of both trains) / Relative speed
```

Use sum of speeds if moving in opposite directions, and difference of speeds if moving in the same direction.

### 7.8. Boats and Streams

```
Downstream speed = Speed of boat + Speed of stream
Upstream speed = Speed of boat − Speed of stream
```

**Finding boat speed and stream speed from downstream and upstream speeds:**

```
Speed of boat = (Downstream + Upstream) / 2
Speed of stream = (Downstream − Upstream) / 2
```

### 7.9. Same Distance, Different Speeds (Change in Time)

If the same distance is covered at two different speeds, the change in time can be linked to the change in speed using the fact that distance stays constant.

```
Distance = Speed1 × Time1 = Speed2 × Time2
```

### 7.10. Races

In a race, the distance covered by different runners in the same time can be compared using their speed ratio.

```
If A gives B a head start of x metres in a race of d metres,
A covers d metres while B covers (d − x) metres in the same time
```
